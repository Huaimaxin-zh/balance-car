1）/\*atan2计算反正切，得到角度（弧度制）， / 3.14159 \* 180可将弧度制转为角度值\*/

&#x09;	AngleAcc = -atan2(AX, AZ) / 3.14159 \* 180;

&#x20;   【一定要用vofa看看AngleAcc的跳动正不正常，不正常的话，极大概率是atan2前面的要给-】



2）Angle有零漂的话，先调整AngleAcc，减去AngleAcc的零漂值大概率就能使Angle在零位。



3）10.22 增加了积分限幅和输出偏移，但是感觉对平衡车重心偏前没什么作用



4）10.22 增加了角速度环，同时放弃Angle的水平零度，把重心纳入考虑范围，修改AngleAcc为-=5.0，同时给了-6的输出偏移，成功做出了不抖，较为丝滑的平衡小车，目前会前后小幅移动



5）10.23 把输出偏移置0了，感觉输出偏移给-6会往后倒，同时还发现一点，就是大力推一下会叠加速度，一直往一个方向跑，明天早上过来加个速度环看看能不能遏制这种情况



6）10.23 增加了速度环，发现果然就是这个问题，加了速度环之后推了也能保持基本静止，而不是往前往后跑了。至于为什么没有早上调试而是凌晨调试，是因为学校关门了，出不去了，下次要赶在十一点前出门，现在只能调车了。
